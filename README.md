# ⚡ Taskly

### A modern and responsive Todo App built with JavaScript.

Taskly is a simple and interactive todo application that lets you **add, edit, update, complete, and delete tasks** with a clean glassmorphism-inspired interface.

**Live Demo:** [Taskly](https://suprio-dev.github.io/Taskly-Todo-App/)

---

## ✨ Features

- Add new tasks
- Edit existing tasks
- Update edited tasks
- Cancel edit mode
- Mark tasks as completed
- Delete individual tasks
- Clear all tasks at once
- Categorize tasks by type
- Set task priorities
- Dynamic task counter
- Completed task counter
- Task completion progress bar with percentage
- Real-time progress status messages
- Empty-state message
- Custom checkbox interactions
- Light and dark mode toggle
- Task creation date and time display
- LocalStorage-based task persistence
- Responsive glassmorphism UI
- Smooth and interactive user experience

## 🔄 How It Works
```text
Enter Task
    ↓
   Add
    ↓
Task Added to List
    ↓
 ┌─────────────────────┐
 │ Complete / Edit /   │
 │      Delete         │
 └─────────────────────┘
          ↓
       Edit Mode
       ↙      ↘
   Update     Cancel
      ↓          ↓
   Save Task   Exit Edit
          ↓
    Dynamic UI Update
```

Taskly uses **JavaScript DOM manipulation** to dynamically create, update, complete, and remove tasks without reloading the page.
